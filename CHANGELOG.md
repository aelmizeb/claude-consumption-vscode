# Changelog

## 0.1.0

- First release: the cyber-fleet panel (agents, tasks, tokens, costs, memory) as a VS Code extension, read from the Claude Code transcripts.
- Placement below the Claude Code chat in the right side bar, or in its own container.
- Session, week and month costs, from `cost-state` lines plus an estimate at public prices.
- Optional status line bridge for the 5h / 7d quota.
- Optional comparison row: what the same tokens would have cost on DeepSeek's most expensive offer (`claudeConsumption.compareWithDeepSeek`).
